# Неоновый Рикошет — HTML5-игра для Яндекс Игр

Готовая к публикации аркадная HTML5-игра на чистом **JavaScript + HTML5 Canvas** с интегрированным **Yandex Games SDK v2** (`YaGames.init()`, `LoadingAPI.ready()`, `GameplayAPI`, межстраничная реклама `showFullscreenAdv()` при проигрыше и переходе между уровнями, автоотключение звука при сворачивании вкладки и защита `localStorage` для режима Инкогнито).

---

## БЛОК 1: Карточка игры для Консоли Яндекс Игр

Ниже приведены полностью готовые данные для копирования в поля вкладки **«Черновик»** в Консоли разработчика Яндекс Игр:

- **Название игры:** Неоновый Рикошет
- **Об игре (Описание):** «Неоновый Рикошет» — динамичная космическая аркада в стиле классического арканоида с яркой неоновой графикой и сочными спецэффектами! Отбивайте энергетический шар платформой, крушите цветные и бронированные блоки, подрывайте плазменные ядра для цепных взрывов и ловите полезные бонусы: мульти-шар, огненную плазму, широкую платформу и защитный щит. Набирайте серии комбо, проходите уникальные уровни и устанавливайте новые рекорды!
- **Инструкция:** Ваша задача — разбить все разрушаемые энергетические блоки на поле, отбивая шар платформой и не позволяя ему упасть за нижнюю границу арены. Подбирайте падающие капсулы с бонусами для усиления платформы и шаров.
  - **Управление на ПК (Desktop):** перемещайте платформу движением мыши или клавишами `←` `→` / `A` `D`. Запуск шара — левая кнопка мыши, `Пробел` или `↑`. Пауза — клавиша `P` или `Esc`, включение/выключение музыки — `M` (или кнопка `🎵`).
  - **Управление на смартфоне и планшете (Mobile):** водите пальцем влево и вправо в любой части экрана для перемещения платформы; коснитесь экрана или отпустите палец, чтобы запустить шар.
- **Категория:** Аркады
- **Дополнительные категории:** Казуальные, Шарики
- **Ключевые слова (теги):** арканоид, рикошет, шарики, неон, блоки, аркада, разбивать кирпичи, реакция
- **Ориентация экрана:** Любая
- **Возрастной рейтинг:** 6+
- **Поддерживаемые устройства:** обоих (Mobile и Desktop)

## БЛОК 2: Пошаговая инструкция по публикации

### 1. Скачивание и упаковка проекта в ZIP-архив
Платформа Яндекс Игры требует, чтобы файл `index.html` находился **строго в корне ZIP-архива**, а не внутри вложенной папки.

1. Скачайте репозиторий игры на компьютер (`git clone` или **Code → Download ZIP** на GitHub с последующей распаковкой).
2. Откройте папку с игрой, где лежат файлы `index.html`, `style.css` и `game.js`.
3. **Важно:** выделите **само содержимое папки** — файлы `index.html`, `style.css`, `game.js` (служебную папку `.git` и `README.md` включать в архив не нужно), а **не саму внешнюю папку проекта**.
4. Упакуйте выделенные файлы в формат `.zip`:
   - **Windows:** выделите `index.html`, `style.css`, `game.js` → правый клик мыши → **Отправить → Сжатая ZIP-папка** (назовите архив `game.zip`).
   - **macOS:** выделите `index.html`, `style.css`, `game.js` → правый клик мыши → **Сжать объекты (3)** (переименуйте созданный `Архив.zip` в `game.zip`).
   - **Терминал (Linux / macOS / Git Bash):** выполните команду прямо внутри папки проекта:
     ```bash
     zip game.zip index.html style.css game.js
     ```

### 2. Переход в Консоль разработчика Яндекс Игр
1. Перейдите в Консоль разработчика по ссылке: https://yandex.ru/games/developers/
2. Авторизуйтесь под своим аккаунтом **Яндекс ID** и нажмите **«Открыть консоль»** (при первом входе примите условия оферты и заполните базовый профиль разработчика).

### 3. Создание черновика и заполнение карточки игры
1. В верхнем правом углу Консоли нажмите кнопку **«Добавить приложение»**.
2. Откроется вкладка **«Черновик»** новой игры. Убедитесь, что основной язык карточки установлен как **Русский**.
3. Последовательно скопируйте и вставьте подготовленные тексты из **БЛОКА 1** выше:
   - **Название** → `Неоновый Рикошет`
   - **Описание (Об игре)** → текст описания из Блока 1 (431 символ — укладывается в рекомендуемый диапазон 200–500 символов).
   - **Как играть (Инструкция)** → текст инструкции из Блока 1 с описанием управления для ПК и мобильных устройств.
   - **Категории** → выберите основную категорию **«Аркады»**, затем дополнительные: **«Казуальные»** и **«Шарики»**.
   - **Теги (ключевые слова)** → укажите теги из Блока 1.
   - **Ориентация** → выберите **«Любая»** (игра автоматически адаптируется и под портретный, и под альбомный экран).
   - **Поддерживаемые платформы / устройства** → отметьте **Десктоп** и **Мобильные устройства (iOS, Android)**.
   - **Возрастной рейтинг** → укажите **6+** и отметьте в анкете отсутствие насилия, ненормативной лексики, азартных механик и внутриигровых покупок.
   - **Облачные сохранения / Авторизация** → оставьте выключенными (рекорд сохраняется локально с безопасным резервом в оперативной памяти для режима Инкогнито).

### 4. Загрузка ZIP-архива в раздел «Файлы игры»
1. Прокрутите страницу черновика до блока **«Файлы игры»** (раздел загрузки исходного архива).
2. Перетащите подготовленный файл `game.zip` в область загрузки или выберите его через диалоговое окно.
3. Дождитесь завершения автоматической проверки архива сервером Яндекса (статус изменится на **«Загружено» / «Архив проверен»**).
4. После обработки архива нажмите на ссылку **черновика (Предпросмотр)** в верхней части страницы и протестируйте игру прямо внутри оболочки Яндекс Игр:
   - проверьте старт игры, управление мышью и касаниями;
   - убедитесь, что звук выключается кнопкой `🔊` и автоматически затихает при переключении вкладки браузера;
   - проверьте прохождение уровня и проигрыш — в эти моменты вызывается межстраничная реклама `ysdk.adv.showFullscreenAdv()`.

### 5. Настройка промо-материалов
Подготовьте и загрузите графические материалы в соответствующие поля вкладки **«Черновик»**:
- **Иконка игры (`512×512` px):** формат PNG или JPG, квадратное изображение без скруглённых прозрачных углов, без рамок и без текста (например, яркий неоновый шар, разбивающий светящийся блок).
- **Горизонтальная обложка (`1920×1080` px):** формат PNG или JPG для витрины на ПК и планшетах — красочный арт или композиция с названием и динамикой рикошета.
- **Вертикальная обложка (`1080×1920` px):** формат PNG или JPG для мобильного каталога Яндекс Игр (важные элементы композиции располагайте ближе к центру, избегая перекрытия системными бейджами по краям).
- **Скриншоты геймплея (рекомендуется 2–5 шт.):** реальные снимки экрана из запущенной игры без рамок браузера и курсора мыши (желательно загрузить как горизонтальные `1920×1080`, так и вертикальные `1080×1920` варианты).

### 6. Отправка на модерацию
1. Нажмите кнопку **«Сохранить»** внизу черновика и проверьте индикатор заполненности карточки — все обязательные поля должны быть отмечены без ошибок.
2. Проведите быструю финальную самопроверку перед модерацией:
   - игра открывается в режиме **Инкогнито** (при заблокированных сторонних cookies) без ошибок в консоли (`F12`);
   - в `index.html` подключён официальный скрипт `https://yandex.ru/games/sdk/v2`, а при загрузке вызывается `YaGames.init()`;
   - межстраничная реклама корректно вызывается между уровнями и при окончании игры.
3. Нажмите кнопку **«Отправить на модерацию»** в верхней панели страницы приложения.
4. Статус черновика сменится на **«На модерации»**. Проверка обычно занимает от **2 до 5 рабочих дней**. После одобрения кнопка **«Опубликовать»** станет активной (либо игра опубликуется автоматически в зависимости от выбранной настройки публикации), и проект появится в каталоге Яндекс Игр!
